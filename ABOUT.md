### Summary
This demo demonstrates scatter and bubble charts using VisuallyJS in Svelte.

### Components Used
- `ScatterChartComponent`: Renders scatter plots.
- `BubbleChartComponent`: Renders bubble charts where a third dimension is represented by bubble size.

### Component Options
Both components use:
- `options`: Configuration object for chart data, axes, and styles.
- `className`: Optional CSS class for the chart container.

### Stylesheet Requirement
Include `visuallyjs.css` for proper rendering.

```css
@import "@visuallyjs/browser-ui/css/visuallyjs.css";
```
